How GradeMate scores an answer

1

Encode

Reference + student text are normalised, tokenised and embedded with sentence-transformers/all-MiniLM-L6-v2.

2

Engineer features

Five signals: keyword overlap, TF-IDF cosine, semantic cosine, length ratio, bigram overlap.

3

ML branch

RandomForestRegressor and GradientBoostingRegressor each predict a normalised score in [0, 1].

4

DL branch

A 3-layer MLP regression head reads concat[ref, stu, |diff|, prod] over MiniLM embeddings.

5

Stack

Ridge meta-regressor blends the three predictions into a single calibrated score.

6

Calibrate

Output is clamped to [0, 1] and scaled by max-marks. A verdict label is attached for quick review.
